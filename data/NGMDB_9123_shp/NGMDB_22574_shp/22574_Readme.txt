NOTE: This file contains transcribers notes to accompany the original file (readme.pdf).

This data is a conversion product and should not serve as the primary source for the complete geologic information for this area. To obtain complete information, please go to https://pubs.usgs.gov/of/1999/of99-172/.  This information may be found as referenced below:

Publisher:	U.S. Geological Survey	
Title:		Preliminary digital geologic map of the Santa Ana 30' X 60' quadrangle, southern California
Author:		Morton, D.M., Hauser, R.M., and Ruppert, K.R.
Original NGMDB identifier: 22574


Purpose: This file set is intended to make outdated Arc/INFO e00 files available as open-format shapefiles. No modification to files has been made. Projection was not changed. 

Process: e00 files were imported to coverage, then converted to shapefile using the ArcMap commands “Import from e00 (conversion)” and “Feature Class to Shapefile” respectively. Related tables were preserved by opening in ArcMap and exporting to txt.   

E00 files convert to (description extracted from readme.pdf):
	sa2_geo.e00 (Contacts, faults, geologic unit labels) =
		sa2_geo_arc.shp
		sa2_geo_poly.shp
	sa2_ano.e00 (Annotation subclasses) =
 		sa2_ano_anno_faults.shp
		sa2_ano_anno_geo.shp
	sa2_str.e00 (Attitudes and their dip values) =
		sa2_str_anno.shp
		sa2_str_point.shp
		sa2_str_arc.shp
	sa2_point.e00 (Fold axes and Fold axes ornamentation) = 
		sa2_point_point.shp
		sa2_point_arc.shp
